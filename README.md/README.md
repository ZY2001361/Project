# 基于SpringBoot的学生宿舍报修管理系统的设计与实现
项目背景与意义

随着高校宿舍管理规模扩大，传统的纸质报修、人工报修模式存在效率低、追踪难、数据混乱等问题。为解决学生报修流程繁琐、后勤维修响应不及时、维修进度不明确等痛点，本项目基于 Spring Boot 框架开发学生宿舍报修管理系统，旨在通过数字化手段优化报修流程，实现 “学生便捷报修、维修人员及时处理、管理员高效派单、数据可追溯” 的全流程管理，提升宿舍管理服务质量与师生的生活质量

相关技术

后端框架：Spring Boot 

持久层：MyBatis

数据库：MySQL 8.0+

前端技术：Vue 3 + Element Plus

开发工具：IntelliJ IDEA

核心功能模块

用户管理模块

多角色支持：学生（报修发起者）、维修人员（处理报修）、管理员（系统配置与派单）。
功能：用户注册、登录、密码修改、个人信息维护（如学生绑定宿舍号，维修人员绑定擅长维修类型）。

报修提交模块

学生可在线提交报修单，包含：宿舍号、报修类型（水电故障、家具损坏、网络问题等）、问题描述、上传故障图片（可选）、联系方式等。
支持报修单状态实时查询（待受理、处理中、已完成、已取消）。

维修派单与处理模块
管理员接收报修单后，根据维修类型、维修人员等因素进行任务分配

维修人员接收派单通知，更新处理进度（如 “已接单”“维修中”“需备件”），完成后上传维修结果，提交验收。

进度追踪与评价模块
学生可实时查看报修单处理进度，维修完成后对服务质量进行评分（1-5 分）与评价。
系统自动记录评价数据，为维修人员绩效考核提供依据。
